01Employees_DB

Employee & Manager Analysis

This query uses a LEFT JOIN to show employees, their job roles, and their managers. It sorts employees alphabetically by last name.

✓ Query ran successfully14 rows returned

SQL Query

SELECT
    E.lastname AS "Employee",
    E.designation AS "Employee_Role",
    M.lastname AS "Manager",
    M.designation AS "Manager_Role"
FROM employees AS E
LEFT JOIN employees AS M
    ON E.manager = M.id
ORDER BY E.lastname ASC;
02Hospital_DB

Hospital Admissions Analysis

This query joins four tables to show each patient’s diagnosis, last name, province, and doctor.

✓ Query ran successfully100 rows returned

SQL Query

SELECT
    admissions.diagnosis AS Diagnosis,
    patients.last_name AS PatientLastName,
    provinces.name AS PatientProvince,
    doctors.last_name AS DoctorLastName
FROM admissions
JOIN patients
    ON admissions.patient_id = patients.patient_id
JOIN provinces
    ON patients.province_id = provinces.province_id
JOIN doctors
    ON admissions.attending_doctor = doctors.doctor_id
ORDER BY admissions.diagnosis DESC;
03Sales_DW

Retail Sales by City

This query joins sales, products, and stores. It uses SUM and GROUP BY to count how many Cheese 200g units were sold in each city.

✓ Query ran successfully4 rows returned

SQL Query

SELECT
    dimStore.City AS City,
    SUM(FactProductSales.Quantity) AS Cheese_Sales
FROM FactProductSales
JOIN dimProduct
    ON FactProductSales.ProductID = dimProduct.ProductID
JOIN dimStore
    ON FactProductSales.StoreID = dimStore.StoreID
WHERE dimProduct.ProductName = 'Cheese 200g'
GROUP BY dimStore.City;
